# 户外地垫市场分析

当前有效规范是 [SPEC 3.1](docs/SPEC.md)。本批次只使用 `data/raw/0920new` 内 2024.08—2026.07 的 24 个按月文件，交付整体市场、PP市场、高客单价市场、Genimo品牌四部分分析。详细处理步骤和人工复算方法见 [数据处理流程与人工验算](docs/数据处理流程与人工验算-20260922.md)，执行与审查记录见 [TASKS](docs/TASKS.md) 和 [REVIEWS](docs/REVIEWS.md)。

## 当前有效口径

- 24个源文件共48,000行。逐行将“小类目”和“小类BSR”按换行位置对应，只保留 `Outdoor Rugs` 的 BSR 1—100（含100），得到45,935条候选子体行。
- 2025.08有354行仅一个类目名称、却有两个排名，不能可靠对应，标记 `AMBIGUOUS_CATEGORY_RANK` 并排除；受影响的月度、MOM、YOY和年度比较都显示范围提示。
- 统计单元是“月份+父ASIN”，父ASIN缺失时回退ASIN，再回退源行ID；当前形成1,272个父体月份组合。同月ASIN重复将阻止发布，本批次为0组。
- 父体月销量不相加：一致值直接取；严格多数（>50%）取众数；其余包括50%平局取中位数并标记 `MEDIAN_CONFLICT`。
- 有效子体销售额只累加“子体销量”和“子体销售额”同时为有效非负数的子体行。源字段“月销售额($)”只回勾，不在父体下相加。
- 有效子体均价=有效子体销售额÷有效子体销量。空白保留为空，不转换成0；0销量但正销售额视为无效矛盾。
- PP按父体候选子体标题中完整单词 `plastic` 的多数归类，高客单价市场是其补集；整体市场=PP+高客单价市场。Genimo是同一父体池中的品牌视角。
- MOM=本月÷上月−1；YOY=本月÷去年同月−1。年度YOY只比较双方共同存在的月份，不把不完整年度当作全年。
- 父体BSR使用候选子体 `Outdoor Rugs` BSR中位数分层；不使用最小BSR代表整个父体。
- 不计算利润；供应方数据属于估算，程序能证明处理、公式与交付一致，不能证明估算等于真实成交。

## 构建与检验

```powershell
npm run build:parent
npm run test:parent
npm run test:parent:formula
```

`npm run test:parent`会独立重新读取24个源文件，重新计算Outdoor Rugs候选范围，核对父体分组、PP/高客单价回加、BSR分层、共同月份年度、XLSX缓存和HTML批次。公式审计独立求值378,821个保存公式，并用内存副本测试子体销售额+100、全部清空、明确0三种情况。

本机完整工作簿通过XlsxWriter生成。Artifact Tool导入15MB完整簿耗时过长，因此只用它做代表页的裁剪预览；公式正确性由独立公式解释器与模型逐项核对。桌面Excel整簿重算是单独的人工验收层，不用本地测试结果冒充。
