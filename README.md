# 户外地垫市场分析

当前有效规范是 [SPEC 3.3](docs/SPEC.md)。本次在3.2基础上把父体Q列“月销量”、T列“月销售额($)”和BSR改为父体组内有效值平均；旧Excel、HTML和JSON需要按3.3重新构建后才能作为最终数字交付。详细处理步骤和人工复算方法见 [数据处理流程与人工验算](docs/数据处理流程与人工验算-20260922.md)，执行与审查记录见 [TASKS](docs/TASKS.md) 和 [REVIEWS](docs/REVIEWS.md)。

## 当前有效口径

- 24个源文件共48,000行。`小类目`只作为回勾字段，不作为筛选条件；按“小类BSR”解析，只要存在1—100（含100）的有效排名就进入候选池。新口径候选行数必须重新构建后确认。
- 多值“小类BSR”全部保留并标记 `MULTI_BSR`；行级BSR使用有效1—100排名的平均数，最小排名只作诊断，不再使用Outdoor Rugs文本与排名位置配对。
- 统计单元是“月份+父ASIN”，父ASIN缺失时回退ASIN，再回退源行ID；当前形成1,272个父体月份组合。同月ASIN重复将阻止发布，本批次为0组。
- 父体Q列月销量和T列月销售额($)不相加，分别对同一月份+父ASIN内的有效非负值求平均；保留有效数、覆盖率、最小值、最大值和 `AVERAGE_CONFLICT`。
- 有效子体销售额仍只累加“子体销量”和“子体销售额”同时为有效非负数的子体行，但只作为覆盖诊断，不替代Q/T父体主销售额。
- 父体主均价=父体平均T÷父体平均Q；子体诊断均价=有效子体销售额÷有效子体销量。空白保留为空，不转换成0；0销量但正销售额视为无效矛盾。
- PP按父体候选子体标题中完整单词 `plastic` 的多数归类，高客单价市场是其补集；整体市场=PP+高客单价市场。Genimo是同一父体池中的品牌视角。
- MOM=本月÷去年同月−1；YOY=本年与上一年共同覆盖月份汇总比较。年度YOY只比较双方共同存在的月份，不把不完整年度当作全年。
- 父体BSR使用候选行级BSR平均数再取父体平均分层；不使用最小BSR代表整个父体。
- 不计算利润；供应方数据属于估算，程序能证明处理、公式与交付一致，不能证明估算等于真实成交。

## 构建与检验

```powershell
npm run build:parent
npm run test:parent
npm run test:parent:formula
```

`npm run test:parent`需要按SPEC 3.3改造后独立重新读取24个源文件，按小类BSR计算候选范围，核对父体分组、Q/T平均、BSR平均、PP/高客单价回加、去年同月MOM、共同月份年度YOY、XLSX缓存和HTML批次。当前3.1/3.2公式审计结果不作为3.3验收结果。

本机完整工作簿通过XlsxWriter生成。Artifact Tool导入15MB完整簿耗时过长，因此只用它做代表页的裁剪预览；公式正确性由独立公式解释器与模型逐项核对。桌面Excel整簿重算是单独的人工验收层，不用本地测试结果冒充。
