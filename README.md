# 户外地垫市场分析

当前规范为 [SPEC 2.1](docs/SPEC.md)，执行与验收分别记录在 [TASKS](docs/TASKS.md) 和 [REVIEWS](docs/REVIEWS.md)。交付整体市场、PP市场、高客单价市场、GENIMO品牌四部分分析，以及一份可追溯计算的XLSX。

## 当前数据与口径

- 唯一主源：`data/raw/地垫-卖家精灵市场数据.xlsx`，原文件只读。
- 覆盖2022.06—2026.07的50个月，73,810条业务原始行。隐藏月度表也纳入；先筛小类BSR 1—100（含100）再按父ASIN去重，当前分析主池为5,190个Listing月次。
- 处理顺序固定为：BSR筛选 → 父ASIN去重并选代表 → 代表标题匹配完整单词plastic → PP/高客单价拆分 → PP+高客单价回加整体市场。
- 父ASIN是唯一分析统计单位。代表优先级为有效BSR最小、销售字段完整、价格完整、数值源行最小；不合计同一父ASIN下全部子体销量。
- 高客单价市场是BSR主池中未命中plastic的父ASIN补集，没有额外价格门槛。不存在未经BSR筛选的另一套整体业务盘，也不额外截成100个。
- GENIMO从同一BSR筛选、父ASIN去重主池中按代表品牌筛选；GENIMO PP是GENIMO与PP的交集。整体、PP、高客单价和GENIMO都使用同一主池。
- 月度MOM是项目约定的“去年同月比较”；年度YOY只比较相邻年的共同覆盖月份。年度数量标为Listing月次。表头和说明必须明确各自分母月份。
- 空值、无样本、真实0分别处理。只分析源字段，不计算利润。卖家精灵数据是源估算，程序不能保证供应方估算等于实际成交。

## 构建与检验

```powershell
npm run build:delivery
npm test
npm run test:inputs
```

Python默认使用本机Codex工作区运行时。其他机器设置`SPEC21_PYTHON`为具有xlsxwriter的Python绝对路径。构建顺序为统一源模型、公式计划、实际公式求值、XLSX导出、HTML/JSON/Markdown及构建清单。公式与独立源模型不一致会中止Excel导出。

完整公式簿超过200万条公式，构建和首次重算需要时间。Artifact Tool导入旧完整工作簿时内存溢出，当前使用流式XLSX写入与独立、限定函数范围的求值器。不以缓存扫描代替求值；未运行桌面Excel时，验收记录必须写明这一边界。

`npm test`检验解析边界、独立源XML读取、保存公式/缓存及跨文件一致性；`npm run test:inputs`在内存副本中检验数值变化、BSR代表切换、空值/零和规划分配，正式源与正式XLSX不被修改。机器证据保存在`tmp/spec21_*audit.json`，可交付结论记录在docs。

## 人工复核与修改

本轮代表行变化、BSR先筛后按父ASIN去重的主池、2025.09与2026.07逐步手算示例见 [SPEC2.1修复与人工复核](docs/SPEC2.1-修复与人工复核-20260914.md)。新主池工作簿和报告已在本地重建并通过独立源审计、公式缓存审计和输入扰动验证；旧批次数字仍只保留作历史对照。

1. 先核对00页的主源SHA256及月份范围。
2. 在90页按月份筛选，核对源表名、源行、原始BSR和数值BSR。标题从完整富文本恢复，避免超链接简称截断。
3. 91页查看成员源行号、V列代表索引、销量/金额/价格及各池标记。
4. 92页查看COUNTIFS/SUMIFS聚合；01—04页看月度、份额、均价和去年同月比较；05页看覆盖月份及比较分子/分母；06页看粗细档月度及年度。
5. 07页核对整体Top100组成和GENIMO进/留/退；08页B3可输入非负整数目标新增链接总量，默认空。
6. 最后查看93页校验。校验页不向业务公式提供输入。

90页既有行的I/K/L/M数值修订会联动重算。新增/删除行、月份、父ASIN键、标题/品牌归类或换源属于结构变更，需要重新导入。源ASIN仅作回勾字段，不作为缺失父ASIN时的业务统计键。HTML/JSON/Markdown是批次快照，编辑Excel后不会自动更新这些外部文件；正式源修订经确认后重新构建整批交付。
