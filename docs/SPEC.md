# SPEC：户外地垫市场分析与可回勾交付

版本 3.1，2026-09-22。替代3.0中的50%销量平局、缺失金额填零、年度错期与BSR小数分层规则。用户本次确认：只统计 **Outdoor Rugs 小类前100（含100）**。

## 1. 交付与主源

- 四个部分：整体市场、PP市场、高客单价市场、Genimo品牌。Genimo是品牌视角，不是互斥市场。
- 只使用 `data/raw/0920new` 内2024.08—2026.07的24个按月文件。旧总表和参考表不进入本批次计算。
- 原始文件只读；记录文件名、业务Sheet、月份、行数、排除原因和SHA-256。文件月份必须唯一连续；业务Sheet与月份、表头字段及顺序必须匹配。违反时停止构建。
- 交付目录：`outputs/20260920-new-source-parent-model/`。一份公式XLSX，以及共用同一模型的HTML、JSON、Markdown、构建清单。
- 不计算利润；FBA、毛利率、Coupon仅保留原始快照，不参与业务推导。

## 2. 确定候选池

1. 每条源行的“小类目”和“小类BSR”按原始换行逐项对应；只取名称等于Outdoor Rugs（忽略大小写、两端空格）的排名。
2. 不从多个小类排名中选最小值。例：Outdoor Rugs=7、Area Rugs=4，应使用7。
3. 没有Outdoor Rugs的行标记 `OTHER_CATEGORY`；名称和排名数量不匹配或Outdoor Rugs重复时标记 `AMBIGUOUS_CATEGORY_RANK`。
4. 排名必须为正整数或等值的`.0`文本。只保留1≤排名≤100；空白、负数、非整数、无法解析、超过100分别排除并保留来源。
5. 同月ASIN重复必须阻止发布，不能直接重复求和。当前数据无重复不代表将来自动忽略此规则。

候选池包含多条子体，因此“BSR前100”不意味着只能保留100行。原始90页保留未进入候选池的行；91页仅保留合格候选。

## 3. 父体统计单元

- 分组键：月份+父ASIN。父ASIN缺失依次回退ASIN、源行ID，不跨月去重。
- 原始明细不删除；92页每个父体月份一条汇总。不同指标分别计算，不使用一条代表行代替整个父体。
- 91页按月份、父体键、源月销量、ASIN排序，使同一父体的候选记录连续，便于公式回算；源文件和源行号始终保留。
- 父体估计销量涉及源系统定义的整个父体，可能包括BSR不在前100的变体。本文“市场”指BSR合格子体所对应的候选父体样本，不能称为全站真实市场普查。

## 4. 父体月销量估计

父体行级月销量不能相加。同月同父体的有效非负数值按以下顺序处理：

1. 没有有效值：留空，`NO_VALUE`；
2. 全部值一致：取该值，`CONSISTENT`；
3. 某个值严格超过有效行数50%：取众数，`MODE`；
4. 其他情况（包括50%平局）：取中位数，`MEDIAN_CONFLICT`。

每个父体保留众数、次数、占比、中位数、不同值数、最小值、最大值及有效值行数。所有不同值数>1的父体均进入冲突诊断，不能只统计中位数回退组。最小—最大用于源值敏感度核查，不是统计置信区间。

该规则是可复核的清洗估计，既不是官方去重算法，也不保证恢复真实成交。中位数可能为小数，保留精度，不悄悄取整。汇总只累加有值父体，并显示缺失销量父体数；整个范围没有有效销量时留空。

## 5. 子体销量、销售额、均价

- 有效子体要求子体销量与子体销售额都为有效非负数值；零销量但正销售额视为无效矛盾。明确0/0保留为零。
- 仅一项有值或者两项均缺失均不进入有效子体统计；缺失不填零。
- 有效子体销量=有效行子体销量之和；有效子体销售额=同一批有效行子体销售额之和。
- 父体没有有效行时，子体销量、销售额留空，状态 `NONE`；部分候选行有效为 `PARTIAL`；全部候选行有效为 `FULL`。
- 子体覆盖率=有效候选子体行数÷候选子体行数；它不是已采集变体数÷全部变体数。即使FULL也不能称为完整父体真实收入。
- 均价=有效子体销售额÷有效子体销量，分母必须>0。不得用有效子体金额除以父体估计销量，因为覆盖范围不同。
- 不累加源字段“月销售额($)”作为父体收入；不以当前价格回填历史金额。该字段仅保留，并计算隐含售价=原始月销售额÷原始月销量、与标价差异率=隐含售价÷标价−1。
- 部分覆盖金额变化只能称为已观测子体金额变化。分析必须同时列示本期与基期覆盖率，不能单独据此断言完整市场增长。

## 6. PP、高客单价和Genimo

- 在父体候选子体的非空标题中，完整单词`plastic`命中率≥50%暂归PP，其他归高客单价；50%平局与混合标题均显示提示供复核，不另行用销售额改分类。
- 高客单价为不命中plastic的补集业务名称，不能当作实际价格必然较高的证明。
- Genimo来自同一父体池，按有效品牌中Genimo多数识别。原始品牌与标题保留供复核。
- 整体父体数、父体估计销量、有效子体销售额分别等于PP+高客单价。按聚合字段核对；不可将均价或增长率直接相加。
- Genimo整体份额分母为整体市场同指标；Genimo PP份额的分子为Genimo且PP父体，分母为全部PP父体。有效金额份额同时展示两侧覆盖率。

## 7. 时间与BSR分层

- MOM=本月÷上一自然月−1；YOY=本月÷去年同月−1。表头写清中文基期。原表增长率不覆盖本报告重算值。
- 本期或基期无有效值、基期为0，增长率留空。无记录不当作0销售。
- 年度YOY必须使用相同月份集合。当前2025对2024仅比较8—12月；2026对2025仅比较1—7月；2024无基期。列示双方月份、数值和覆盖率，部分年度不得标“全年同比”。
- 父体BSR分层使用候选子体BSR中位数，最小值仅诊断。粗档为(0,20]、(20,50]、(50,100]；五档为(0,5]、(5,10]、(10,20]、(20,50]、(50,100]。例如20.5归中部、5.5归6—10档，无边界缺口。
- 三档与五档各自完整分区；两套分层不能混在一起再加总。
