## 1. 任务、优先级与交付范围

用户最新指令 > 原始需求 > 本规范 > 参考表结构 > 旧脚本与结果。只使用给定原始数据，不计算利润，不将领导参考数字当验收答案，不用竞品快照替换主源。

四个业务部分：整体市场、PP市场、高客单价市场、GENIMO品牌。唯一分析池是每月先筛小类BSR 1—100（含100），再保留每一条候选源行，不按父ASIN去重。GENIMO是同一候选行池中的品牌视角，不是第三个互斥市场。整体市场由PP与高客单价市场相加得到。

交付一份XLSX、HTML、JSON、优化版/极速版Markdown及构建清单。同一批次主源模型导出所有文件，记录sourceSha256、batchId、generatedAt、截止月份、specVersion及各文件指纹。保留现有HTML视觉风格、数据总览、四部分编号、下拉导航、小节折叠、无序列表和交互图表。历史数据库构建器不得覆盖正式路径。

## 3. Listing候选行、分类

每一条满足BSR 1—100的源行都是一个统计候选Listing月次；同一父ASIN下多个子体行分别计入，不能合并或相加后再去重。月份+源行号是稳定行级键；父ASIN、ASIN和源工作表全部保留用于回勾与重复诊断。父ASIN缺失不改变候选行纳入规则。当前口径不选代表行。

PP在BSR筛选后按候选行商品标题不区分大小写的完整单词plastic匹配（词字符ASCII字母/数字/下划线；plastics、plasticity、plastic123不命中）。命中归PP，未命中归高客单价；高客单价是PP的补集，无额外价格/材质门槛。GENIMO在同一候选行池中按候选行品牌trim后不区分大小写精确匹配；GENIMO PP是GENIMO与PP的交集。

整体市场数量/销量/金额逐月等于同一BSR候选行池中PP与高客单价之和。GENIMO整体份额=GENIMO候选行池指标/整体候选行池指标；GENIMO PP份额=GENIMO PP指标/PP候选行池指标。份额用比值，增长率用比值减1。

## 4. BSR池和分层

有效BSR为正整数，允许N.0；空、零、负数、非整数小数、无有效数值文本无效。多个值取最小有效正整数，保留原文；不得从负数或非整数里截出伪正排名。先筛1≤BSR≤100（含100），随后保留每条候选源行。

严格按用户的数值筛选条件保留全部符合1≤BSR≤100的原始候选行，不按父ASIN或ASIN去重，也不额外截取最多100条。记录原始候选数、候选父ASIN数、候选行数和截去数；截去数应为0。小于100提示样本少于100，不补齐；大于100披露并列或多个源小类排名样本，不伪造单一连续榜单。层级按候选行源BSR划分，不按结果序号。

| 池 | 定义 |
|---|---|
| BSR 1—100分析池 | 原始行先筛1—100（含100），保留每条候选行；所有业务部分从此池取数 |
| PP市场 | 候选行商品标题命中plastic |
| 高客单价市场 | 候选行商品标题未命中plastic，作为PP补集 |
| 整体市场 | 候选行池中的PP与高客单价并集，数量/销量/金额必须相加回一致 |
| GENIMO品牌 | 从同一候选行池按品牌筛GENIMO；GENIMO PP为品牌与PP交集 |

不再维护“全量整体盘”和“独立Top100盘”两套业务结果。2025.09的114条BSR候选行全部进入分析池，其中PP为65条、高客单价为49条；96个父ASIN只作为重复结构审计数，不是业务商品数。

粗档：头部1—20、中部21—50、尾部51—100。细档：1—5、6—10、11—20、21—50、51—100。粗细分别回勾各自同一池。并列可使一档商品数超过区间宽度，须披露。

## 5. 指标、缺失、时间和质量

- 销量/金额有效数值求和；无有效数值显示空。有样本真实0保留0。无样本、指标缺失、真实0三种状态分开且跨文件一致。
- 平均标价=有效价格合计/有效价格数。
- 加权成交均价=销量>0且销量/金额都有效的配对金额合计/配对销量合计。
- 月度MOM采用项目定义：本月/去年同月−1。不再展示连续自然月环比列。
- 年度YOY按相邻自然年共同覆盖月份集合：2026.01—07对2025.01—07；2023对2022仅06—12。缺失年份不能跳过。总量期与比较期可能不同，分别显示。
- 年度行列出本期覆盖、比较月份、比较期分子、基期分母、状态。无基期、基期缺失或≤0则增长率为空且给原因。
- 年度商品数量默认为“Listing月次”（月度数累加）；另算跨月去重后才可称年度独立Listing。
- 年度/同周期分层累计当月BSR候选行池，禁止全年重新筛选或重新截100行。
- FBA、毛利率、Coupon只保留原始证据；不在前端、策略中参与分析；不推导成本、净成交价、佣金、利润、广告、库存指标。

各月保留原始数、BSR有效数、候选行数、候选父ASIN诊断数、重复父ASIN行数、销量/金额/价格有效数、缺失数、覆盖率。两期样本数量并列。质量政策：原始或候选行样本相对去年同月或上月变化>30%，或销售字段覆盖率<95%，标“可比性受限”；阈值只是审查提示，不是市场事实。表、图附近及结论显示提示。少于100另标样本不足。

## 8. 2027策略与规划

用最近实际可用的共同覆盖期，比较BSR候选行池整体/PP/高客单价/GENIMO规模、增长、份额、价格和层级效率，明确证据、建议、条件、限制。不预设中部必然最佳，不需要利润证据。

可执行条件基于已知字段，例如连续两个月份额、销售额及BSR方向；阈值/月数是建议政策，必须写明。可比性受限先核验，不自动扩量。尺寸/颜色/花型提取若无可靠规则和覆盖，明确“未可靠提取”，不虚构趋势。
