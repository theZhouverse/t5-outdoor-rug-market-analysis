# SPEC：户外地垫市场分析与可回勾交付

版本 3.7，2026-09-23。父体主指标按月份+父ASIN计算Q/T平均；BSR独立按月份+BSR值汇总，忽略ASIN，对同月同BSR的Q/T取平均，再按三档输出。3.6及以前的数字按本规范重建。

## 1. 交付与主源

- 四个部分：整体市场、PP市场、高客单价市场、Genimo品牌。Genimo是品牌视角，不是互斥市场。
- 只使用 `data/raw/0920new` 内2024.08—2026.07的24个按月文件。旧总表和参考表不进入本批次计算。
- 原始文件只读；记录文件名、业务Sheet、月份、行数、排除原因和SHA-256。文件月份必须唯一连续；业务Sheet与月份、表头字段及顺序必须匹配。违反时停止构建。
- 交付目录：`outputs/20260920-new-source-parent-model/`。一份公式XLSX，以及共用同一模型的HTML、JSON、Markdown、构建清单。
- 不计算利润；FBA、毛利率、Coupon仅保留原始快照，不参与业务推导。

## 2. 确定候选池

1. `小类目`只作为原始字段和回勾信息保留，不参与候选池筛选；不得因为某一行没有 `Outdoor Rugs` 文本而排除该行。
2. 对“小类BSR”单元格按原始换行拆分并独立解析，不再把“小类目”与“小类BSR”按位置绑定，也不以 `Outdoor Rugs` 名称决定使用哪一个排名。
3. 排名必须为正整数或等值的`.0`文本。一个源行只要存在至少一个1≤排名≤100的可解析小类BSR值，就进入候选池；整行的全部原始排名和解析结果必须保留，不能静默丢弃其他排名。
4. 同一源行包含多个小类BSR时标记 `MULTI_BSR`，每个有效排名生成一条BSR观察记录。
5. 一个源行没有任何有效排名时标记 `INVALID_BSR`；有有效排名但没有任何值落在1—100时标记 `OUTSIDE_TOP100`。
6. 同月ASIN重复必须阻止发布，不能直接重复求和。当前数据无重复不代表将来自动忽略此规则。

候选池包含多条子体，因此“BSR前100”不意味着只能保留100行。原始90页保留未进入候选池的行；91页仅保留小类BSR存在至少一个1—100排名的合格候选。

## 3. 父体统计单元

- 分组键：月份+父ASIN。父ASIN缺失依次回退ASIN、源行ID，不跨月去重。
- 原始明细不删除；92页每个父体月份一条汇总。不同指标分别计算，不使用一条代表行代替整个父体。
- 91页按月份、父体键、源月销量、ASIN排序，使同一父体的候选记录连续，便于公式回算；源文件和源行号始终保留。
- 父体Q/T平均值可能涉及源系统定义的整个父体，可能包括BSR不在前100的变体。本文“市场”指BSR合格子体所对应的候选父体样本，不能称为全站真实市场普查。BSR不写入父体主汇总；它只保留在候选明细和独立分层支线。

## 4. 父体月度主指标平均

父体组内的Q列“月销量”和T列“月销售额($)”不相加，分别对有效值做算术平均。同一月份+父ASIN形成一个父体月度统计单元：

```text
父体月销量 = AVG(Q列月销量的有效非负值)
父体月销售额 = AVG(T列月销售额($)的有效非负值)
```

规则：

1. 空白、`-`、不可解析值和负数不进入平均；
2. 原始明确的0是有效值，进入平均；
3. 没有任何有效Q值时，父体月销量留空，状态`NO_VALUE`；
4. 没有任何有效T值时，父体月销售额留空，状态`NO_VALUE`；
5. 有效值只有部分候选行存在时，保留`PARTIAL`和有效行覆盖率；
6. 全部候选行都有有效值时，标记`FULL`；
7. 平均结果保留小数，不静默取整；
8. 同时保留有效值数、不同值数、最小值、最大值和平均值。不同值数大于1时标记`AVERAGE_CONFLICT`，用于提醒业务检查源值差异。

该规则是对源表父体展示值的去重平均，不等同于真实订单成交，也不等同于把子体销量或子体销售额相加。Q/T必须被业务确认是父体级字段；如果供应方实际按子体或价格变体生成Q/T，平均值只能作为“候选行均值”，不能解释为真实父体总量。

## 5. 子体销量、销售额、均价

- 有效子体要求子体销量与子体销售额都为有效非负数值；零销量但正销售额视为无效矛盾。明确0/0保留为零。
- 仅一项有值或者两项均缺失均不进入有效子体统计；缺失不填零。
- 有效子体销量=有效行子体销量之和；有效子体销售额=同一批有效行子体销售额之和。这两个子体字段保留为覆盖和诊断指标，不再替代Q/T父体月度主指标。
- 父体没有有效行时，子体销量、销售额留空，状态 `NONE`；部分候选行有效为 `PARTIAL`；全部候选行有效为 `FULL`。
- 子体覆盖率=有效候选子体行数÷候选子体行数；它不是已采集变体数÷全部变体数。即使FULL也不能称为完整父体真实收入。
- 子体均价=有效子体销售额÷有效子体销量，分母必须>0。父体主指标均价=父体平均T列÷父体平均Q列，父体主指标和子体诊断均价必须分开列示，不能混用。
- T列“月销售额($)”现在作为父体主销售额的平均输入，不再按行累加；同时保留T列最小值、最大值、有效行数、覆盖率和`AVERAGE_CONFLICT`。不以当前价格回填历史金额；隐含售价只作为源字段诊断。
- 部分覆盖金额变化只能称为已观测子体金额变化。分析必须同时列示本期与基期覆盖率，不能单独据此断言完整市场增长。

## 6. PP、高客单价和Genimo

- 在父体候选子体的非空标题中，完整单词`plastic`命中率≥50%暂归PP，其他归高客单价；50%平局与混合标题均显示提示供复核，不另行用销售额改分类。
- 高客单价为不命中plastic的补集业务名称，不能当作实际价格必然较高的证明。
- Genimo来自同一父体池，按有效品牌中Genimo多数识别。原始品牌与标题保留供复核。
- 整体父体数、父体平均Q列月销量、父体平均T列月销售额分别等于PP+高客单价。按聚合字段核对；不可将均价或增长率直接相加。子体销量和子体销售额仅作为诊断指标，不替代Q/T主指标。
- Genimo整体份额分母为整体市场同指标；Genimo PP份额的分子为Genimo且PP父体，分母为全部PP父体。有效金额份额同时展示两侧覆盖率。

## 7. 时间与BSR分层

- MOM=本月÷去年同月，即本月与上一年度同月份比较，结果是比较倍数，不再减1；YOY=本年共同覆盖月份汇总÷上一年对应共同覆盖月份汇总，即本年与上一年比较，结果同样是比较倍数。表头必须写清中文基期；原表增长率不覆盖本报告重算值。
- 本期或基期无有效值、基期为0，比较倍数留空。无记录不当作0销售。结果为1.00表示相同，0.85表示本期为基期的85%，1.20表示本期为基期的120%。
- 当前只有2024.08—2026.07共24个月，因此没有完整自然年度的YOY：2025只比较2024.08—12与2025.08—12，2026只比较2025.01—07与2026.01—07；2024没有上一年度基期。年度结果必须标注共同月份/YTD，不能写成完整全年同比。月度MOM不能使用上一自然月。
- 月度表的YOY按截至当前月份的共同覆盖月份累计计算；05_年度YOY按该年度全部共同月份汇总计算。2025月度YOY从8月开始，2026月度YOY从1月开始。
- BSR键：月份+BSR值，忽略ASIN。
- BSR平均销量：同月同BSR的有效Q列平均值。
- BSR平均销售额：同月同BSR的有效T列平均值。
- 三档：头部1—20，中部21—50，尾部51—100。档位销量=该档BSR值组的Q平均再取平均；档位销售额=该档BSR值组的T平均再取平均。
